# Выполненное задание L1.6

1. Естественное завершение - горутина завершается сама после выполнения всех итераций цикла.
2. Через канал - остановка через закрытие канала, который мониторится в select
3. Через контекст - отмена через контекст, проверка ctx.Done() в select
4. По времени - автоматическая остановка по истечении времени через time.After
5. Атомарный флаг - использование атомарного флага для сигнала остановки без блокировок
6. Через WaitGroup - синхронизация завершения через счетчик, остановка после wg.Done()

# Выполненное задание L1.4

Данный способ завершение работы использует контекст с отменой: при получении сигнала
вызывается cancel(), которая рассылает сигнал отмены через контекст Done() всем
горутинам. Воркеры и продюсер постоянно мониторят канал; WaitGroup гарантирует,
что главная горутина дождется завершения всех процессов перед закрытием канала и
выходом из программы.

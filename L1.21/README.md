# Выполненное задание L1.21

Плюсы:
1. Принцип единой ответственности - отделяет преобразование интерфейса от логики.
2. Принцип открытости - можно вводить новые адаптеры без изменения кода.
3. Переиспользование - позволяет использовать существующие классы с новыми интерфейсами.

Минусы:
1. Усложнение кода - вводит дополнительные структуры и классы, что также снижает читаемость кода.
2. Производительность - дополнительный расход мощностей.

Примеры использования:
1. Адаптация разных платёжных систем.
2. Адаптация под разные БД которые используются в проекте.
